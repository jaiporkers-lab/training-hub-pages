# Contributing

Read the [build guide](docs/BUILDING.md) and run `swift test --build-system native` before proposing a change. Use generated or synthetic recordings for regression tests.

Keep changes focused. Preserve original recording data and backwards compatibility for the local library. Document changes that affect exports, network access or credential handling.

Use GitHub issues for reproducible bugs and feature discussions. Keep activity files, health data, credentials and personal paths out of issues and pull requests. Report security concerns privately as described in [SECURITY.md](SECURITY.md).
