# Changelog

## 0.8.6

- The welcome screen links to Garmin Personal API settings, shows how to create a key, and lets you paste and verify it in the app.
- Published the source snapshot, build guide, packaging script and security documentation.

## 0.8.5

- Hover to count activities near the cursor on the heatmap. Click to pin a spot and open any matching recording. Inspect centre works on both basemaps.

## 0.8.4

- Exclude recognised indoor and virtual workouts from the heatmap. Outdoor legs of mixed activities stay visible.

## 0.8.0–0.8.3

- Added activity comparison graphs, a personal heatmap, a replayable welcome guide, optional idle-edge trimming and an Apple Maps street basemap.
