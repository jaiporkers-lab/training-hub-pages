# Changelog

## 0.9.0

- Added a bottom-left Report an issue link to the project’s GitHub issues page.

- Renamed the app and site GarHub, with approved GarHub/GH branding and blue/grey light and dark appearances. Existing library and credentials keep their original locations.
- Added running splits, HR drift, covered steady-section comparisons and distance best efforts.
- Added cycling power-duration curves and configurable FTP percentages.
- Added weekly workout/race planning with drag rescheduling, weekly volume goals, distance milestones and library recorded-bests scans.
- Added metric-coloured outdoor tracks, elevation profiles, climb detection and approximate repeated-route comparisons.
- Added aligned health/training charts, rolling recovery trends and descriptive associations with coverage counts.
- Added Home presets and saved layouts.
- Reworked welcome setup into a live walkthrough through the actual app, with highlighted navigation, usage guidance, replay controls and new-feature options at the end.
- Redesigned the public website around general activity types, with accessible theme controls, a fictional activity preview and updated download/security documentation.

## 0.8.6

- The welcome screen links to Garmin Personal API settings, shows how to create a key, and lets you paste and verify it in the app.
- Published the source snapshot, build guide, packaging script and security documentation.

## 0.8.5

- Hover to count activities near the cursor on the heatmap. Click to pin a spot and open any matching recording. Inspect centre works on both basemaps.

## 0.8.4

- Exclude recognised indoor and virtual workouts from the heatmap. Outdoor legs of mixed activities stay visible.

## 0.8.0–0.8.3

- Added activity comparison graphs, a personal heatmap, a replayable welcome guide, optional idle-edge trimming and an Apple Maps street basemap.
