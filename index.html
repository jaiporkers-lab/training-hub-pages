Privacy and security

Controls you can verify.

Activity and health analysis run on the Mac. Garmin sync uses your own key. Apple Maps can receive the viewed area when the street basemap is on. This project page contains no scripts, forms or tracking code.

Garmin credentials
The key is stored in macOS Keychain. The client uses a fixed Garmin HTTPS origin with redirects, cookies and response caching disabled. Transport tests check routes, token renewal and rejection of unexpected destinations.
Import boundaries
Local FIT reads reject symbolic links, special files and files over 100 MB. ZIP tests cover traversal, decompression limits and CRC checks.
Restore safeguards
Restore verifies a private snapshot against the supported SQLite schema, hashes and integrity checks. Regression cases cover a rehashed backup with a trigger and databases that rely on a write-ahead log.
Deliberate sharing
Sensor CSV omits GPS. The prompt builder previews the exact brief and copies on request. Tests cover exclusion of credentials, activity titles, GPS and raw streams.

Review scope. The checks are maintained with the app and have had no independent audit. The personal build is ad-hoc signed and has no Apple notarization. The local library and backups use macOS file permissions. Backup checksums detect changes to the supplied files and do not authenticate their author.

Project notes

A personal project.

Vibe coded, checked on real recordings

Training Hub is an AI-assisted, vibe-coded SwiftUI project. Development uses small release checkpoints, automated regression tests and hands-on checks on a Mac. Calculations in the shipped app run locally.

Build and package on your Mac

Download the Apple silicon build above, or use the repository’s SwiftUI source, tests and packaging scripts to make your own build. Read the build guide

Connect Garmin on the welcome screen

In Training Hub, open Garmin Personal API settings, sign in and create a key. Paste it into the app’s secure field and select Save & test connection. Training Hub stores a verified key in your Mac’s Keychain. You can also import FIT files directly. Garmin Personal API FAQ
